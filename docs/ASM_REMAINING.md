## rdraster.c (372)

The RDroid software rasteriser (0x0040ea50-0x004710e0): polygon set-up (`rdRaster_SetupPoly*`, `EdgeSetup*`, `Grad*`), the per-format span fillers (`Span8/16/R/P_*`: flat / textured / lit / z-buffered / colour-keyed variants, about 220 of them) and the `Draw*` drivers that walk the edges.  This is float -> fixed-point code with x87 control-word switches (floor/ceil via FLDCW, see `build/peephole.py`) and it is the hot loop of the frame (build/BUILD_NOTES.md, Performance: 40-50 percent of a frame is the span fillers), so it stays machine code unless a pixel-exact, equally fast C port is written.  `python -I tools/asm_audit.py` lists the blocking flag of each function.
